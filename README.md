# PhoneRemote

See and control your Windows PC from your phone.

- **Phone:** open https://kuko30tuber-hash.github.io/phone-remote/ (or scan the QR code the PC shows).
- **PC:** download the `pc-app` folder and double-click `Start PhoneRemote.bat`. No install, no settings.

The phone and PC find each other through the free PeerJS service, then the video and controls go directly between them.
